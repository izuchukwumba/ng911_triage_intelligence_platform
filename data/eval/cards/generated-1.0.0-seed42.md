# Data card: `generated-1.0.0-seed42.jsonl`

## Summary

510 synthetic calls from generator 1.0.0 (seed 42): 17 scenario families,
3 phrasings each, with perturbations. It is the training data of B1, the
n-gram baseline, and an early stress test for the rules.

## How it was made

- **Command:** `python -m ntip.generator --n 510 --seed 42`. A test fails
  if the committed file no longer matches the generator.
- **Labels:** `label_source: "generator"`. Labels are computed from the
  template and the labelling rubric, not checked by a person (design v1.2,
  §12.3).
- **No evidence spans:** this generator predates label schema 2.0.

## Uses

- **Suitable:** training B1, which stays fixed as the stable baseline;
  stress-testing on the dev and regression splits.
- **Not suitable:** measuring accuracy. Its 51 phrasings are too narrow to
  train an encoder on: B1e trained on it memorised them.

## Limitations

- Predates labelling guide v2.1 and is kept unchanged so earlier reports
  stay reproducible. Its "fell down the stairs" family has no
  `FALL_FROM_HEIGHT` label.
- Six cue codes appear only in test families.
