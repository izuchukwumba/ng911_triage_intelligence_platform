# Data card: `generated-2.1.0-seed42.jsonl`

## Summary

2,010 synthetic calls from generator 2.1.0 (seed 42). This is generator 2.0
plus four additions, each closing a gap found in B1e's curated-dev errors:
- denials of cues that are not part of the call;
- an all-capitals variant;
- a training family with `NOT_BREATHING` alone;
- Spanish family words drawn at random, keeping their gender.

This is B1e's current training data: the dev and regression splits only.

## How it was made

- **Command:** `python -m ntip.generator --generator 2.1.0 --n 2010 --seed 42`.
  It is built from the generator 2.0 code with an `extras` flag, so
  generator 2.0's output is unchanged.
- **Labels:** `label_source: "generator"`, with spans and statuses as in
  2.0. Each added denial is labelled `negated`, with its own evidence span.

## Uses

- **Suitable:** training B1e (dev and regression only); span and status
  metrics.
- **Not suitable:** claims of accuracy on real calls. The test split must
  not be used for training or tuning.

## Limitations

- The additions were written after seeing curated-dev errors, so curated
  dev is no longer an independent check of those four patterns.
- Spanish is still thin (about 320 calls), and B1e trained on it still
  misreads Spanish family words.
- Labels are generator-intended.
