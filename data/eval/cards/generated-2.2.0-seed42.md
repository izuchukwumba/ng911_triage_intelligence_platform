# Data card: `generated-2.2.0-seed42.jsonl`

## Summary

2,610 synthetic calls from generator 2.2.0 (seed 42). This is generator 2.1
plus 20 families, so that **every labelled cue code appears in the dev,
regression and test splits**:
- 10 dev families for codes that had no dev family;
- 10 regression families for codes that had no regression family.

This lets B1e train on dev alone and be calibrated on regression, whose
families it never saw, for every code (milestone ML-9).

## How it was made

- **Command:** `python -m ntip.generator --generator 2.2.0 --n 2610 --seed 42`.
  It uses the generator 2.0 code with generator 2.1's extras; the output
  of generators 2.0 and 2.1 is unchanged.
- **New phrasings:** written for this version, different from every
  existing family, test families included.
- **Labels:** `label_source: "generator"`, with spans and statuses as in
  2.0.

## Uses

- **Suitable:** training B1e on dev and calibrating it on regression;
  span and status metrics.
- **Not suitable:** claims of accuracy on real calls. The test split must
  not be used for training, calibration or tuning.

## Limitations

- The new families exist because a calibration attempt failed (results
  README). They are written by the same author as every other family.
- Most codes still have only one or two families per split, so a
  calibration fitted on regression reflects few distinct scenarios per code.
- Labels are generator-intended.
