# Data card: `generated-2.0.0-seed42.jsonl`

## Summary

2,010 synthetic calls from generator 2.0.0 (seed 42): 66 scenario families,
279 phrasings and 32 cue codes. Every code appears in both a training and a
test family. Each cue carries its status and exact evidence span (label
schema 2.0), and each location its components.

## How it was made

- **Command:** `python -m ntip.generator --generator 2.0.0 --n 2010 --seed 42`.
  A test fails if the committed file no longer matches the generator.
- **Phrasings:** written by the project author without reference to the
  rules' phrase lists. The rules were not changed to fit them.
- **Spans:** kept through every perturbation, including disfluency,
  misspelling and speech-recognition-style noise.
- **Labels:** `label_source: "generator"` (generator-intended).

## Uses

- **Suitable:** stress-testing the rules on phrasing they were not written
  for (they miss 102 of 334 critical calls on its dev and regression
  splits); span and status metrics.
- **Superseded:** B1e was trained on it as `0.1.0+3cf9758d0861`, but
  generator 2.1 has replaced it as training data.
- **Not suitable:** claims of accuracy on real calls.

## Limitations

B1e trained on it showed four gaps, which generator 2.1 addresses:
- no denial of a cue that is not part of the call;
- no all-capitals text;
- `NOT_BREATHING` never alone in training;
- each Spanish phrasing names one fixed family member.
